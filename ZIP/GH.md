## Архивирование через REST API (для продвинутых)
Если вы хотите создавать полные резервные копии репозиториев для архивации, можно использовать REST API GitHub для генерации так называемых "миграционных архивов" . Это предназначено для перемещения данных между продуктами GitHub, но может использоваться и для целей архивации. Обратите внимание, что такие архивы не включают все данные (например, обсуждения или пакеты)
